# Documentació del TFG

Aquest directori conté tota la documentació de suport i materials de referència utilitzats en el desenvolupament del TFG "Propietat Intel·lectual i Intel·ligència Artificial a Europa: La creació d'obres per IA i la proposta d'una nova categoria d'actius de propietat intel·lectual sense drets morals".

## Estructura i organització

La documentació està organitzada en les següents subcarpetes:

### 1. fonts/
Conté articles acadèmics, llibres, informes i altres fonts consultades durant la investigació. Els fitxers s'anomenen seguint el format:
```
[AAAAMMDD]-[AUTOR]-[TÍTOL_ABREVIAT].[FORMAT]
```
Exemple: `20240215-Cuatrecasas-IA_y_Derechos_Autor.pdf`

### 2. jurisprudencia/
Recull sentències i decisions judicials rellevants per al tema del TFG, especialment aquelles relacionades amb IA i drets d'autor. Els fitxers s'anomenen seguint el format:
```
[AAAAMMDD]-[TRIBUNAL]-[REFERÈNCIA].[FORMAT]
```
Exemple: `20240501-Praga_Municipal_Court-Caso_IA_Image.pdf`

### 3. legislacio/
Inclou textos legislatius, directives, reglaments i altres documents normatius relacionats amb la propietat intel·lectual i la IA a Europa. Els fitxers s'anomenen seguint el format:
```
[PAÍS_O_REGIÓ]-[TIPUS_NORMA]-[NOM].[FORMAT]
```
Exemple: `UE-Directiva-2019_790_DSM.pdf`

### 4. investigacio/
Conté notes de recerca, esquemes preliminars, resultats d'entrevistes o consultes i altres materials de treball no definitius.

## Metodologia de documentació

Aquest TFG segueix una metodologia rigorosa de documentació i referenciació:

1. **Recollida sistemàtica**: Totes les fonts consultades es guarden en la carpeta corresponent amb el format adequat.

2. **Actualització de la bibliografia**: Cada nova font s'afegeix immediatament al fitxer de bibliografia principal (`/6_Bibliografia/bibliografia.md`), seguint el format acadèmic adequat.

3. **Traçabilitat**: Cada cita o referència en el text del TFG es pot rastrejar fins a la seva font original en aquestes carpetes.

4. **Documentació de processos**: Es mantenen notes sobre les cerques realitzades, bases de dades consultades i metodologia d'anàlisi.

## Recomanacions per a la gestió documental

- Guardar sempre els PDF o captures de les fonts web consultades per assegurar l'accés futur.
- Mantenir actualitzat el fitxer de bibliografia a mesura que s'afegeixen noves fonts.
- Actualitzar periòdicament les cerques jurisprudencials per incorporar decisions judicials recents.
- Organitzar les notes d'investigació per temes i subtemes.

## Convencions per a les cites

El sistema de citació utilitzat en aquest TFG és el format APA 7a edició, amb les adaptacions necessàries per a fonts jurídiques. Exemples:

- **Llibre**: Autor, A. A. (Any). *Títol del llibre*. Editorial.
- **Article**: Autor, A. A. (Any). Títol de l'article. *Títol de la revista*, volum(número), pàgines.
- **Sentència**: Tribunal [Abreviatura]. Sentència de [data] (referència).
- **Legislació**: Títol de la norma, referència oficial, data de publicació.
